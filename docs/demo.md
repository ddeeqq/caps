# 시연 가이드

발표 자리에서 청중을 실제로 참여시키는 시연을 기준으로 정리했습니다. 청중이 적거나 와이파이가 불안하면 봇으로 대신합니다.

## 준비물

- 노트북 + 프로젝터 (큰 화면), 진행자 폰 1대 (리모컨)
- **HTTPS 주소**: 모션 센서(레이스)와 카메라(QR 스캔)는 HTTPS에서만 열립니다. 배포 주소를 쓰거나, 같은 와이파이라면 `pnpm dev:https`
- 청중 폰이 접속할 수 있는 네트워크 (행사장 와이파이 또는 배포 주소 + 데이터)

## 사전 점검 (시작 10분 전)

1. `/sync` 를 폰 2~3대에서 열고 나란히 놓습니다. 매 초 같은 순간에 깜빡이고, 화면의 오프셋·왕복 시간이 안정적인지 봅니다.
2. 방을 만들고 봇을 몇 명 넣어 한 바퀴 돌려 봅니다: `pnpm bots --room <코드> --count 6`
3. 노트북 절전·화면 보호기를 끄고, 큰 화면에서 `F`로 전체 화면을 켭니다.
4. 진행자 폰으로 리모컨에 붙어 둡니다 (대기실 하단 **리모컨** 버튼 → QR과 PIN).

## 추천 순서 (약 15분)

| 시간  | 장면                                        | 말할 것                                                              |
| ----- | ------------------------------------------- | -------------------------------------------------------------------- |
| 0:00  | 대기실 QR. 청중 입장, 입장할 때 분위기 설문 | "앱 설치 없이 QR 하나면 됩니다"                                      |
| 1:00  | ① 디지털 눈치게임 2라운드                   | 충돌 장면에서 "79ms 차이" 눈금을 가리키며 시계 동기화 설명           |
| 4:00  | ② 소리 짝꿍 (시간 90초로 줄여서)            | "폰이 대신 소리를 내니 민망하지 않고, 확인하려면 말을 걸어야 합니다" |
| 7:00  | ③ 비대칭 금고 1개                           | 큰 화면은 진행 현황만, 정보는 각자 폰에만 있다는 점                  |
| 10:00 | ④ 인간 카드섹션                             | 불을 끄고 폰을 들게 한 뒤 피날레 문구. 시연의 마무리 장면            |
| 12:00 | 종료 설문 → 리포트                          | 분위기 점수 변화, 처음 말해본 사람 수, 얼굴 보고 말 건 횟수          |

게임 순서와 시간은 방 만들기 화면에서 바꿀 수 있습니다. 시간이 남으면 ⑤ 소수결 서바이벌을 넣으면 반응이 좋습니다.

## 진행 단축키 (큰 화면)

| 키                      | 동작                                    |
| ----------------------- | --------------------------------------- |
| `Space` · `Enter` · `→` | 다음 단계                               |
| `P`                     | 일시정지 / 다시 시작 (게임 시계가 멈춤) |
| `F`                     | 전체 화면                               |

리모컨에서도 같은 진행 버튼과 게임별 명령(검색 끝내기, 연출 시작 등)을 쓸 수 있습니다.

## 문제가 생기면

| 증상                        | 대처                                                                                      |
| --------------------------- | ----------------------------------------------------------------------------------------- |
| 폰에서 QR 주소가 안 열림    | 큰 화면을 `localhost`가 아닌 IP 주소나 배포 주소로 열었는지 확인 (대기실에 경고가 뜹니다) |
| 레이스에서 폰이 안 기울어짐 | HTTPS가 아니거나 권한 거부. 화면의 ◀ ▶ 버튼으로 똑같이 참여 가능                          |
| QR 스캔이 안 됨             | 상대 화면의 4자리 숫자를 입력해도 똑같이 연결                                             |
| 소리가 안 남                | 무음 모드 해제 안내. "소리가 안 나요"를 누르면 의성어 글자가 크게 표시됨                  |
| 누군가 연결이 끊김          | 자동으로 다시 붙고 같은 사람으로 복귀. 진행자는 기다릴 필요 없음                          |
| 청중이 적음                 | `pnpm bots --room <코드> --count 20` 으로 빈자리를 채움                                   |
| 진행 중 질문이 길어짐       | `P`로 일시정지. 남은 시간이 그대로 보존됨                                                 |

## 발표 자료용 캡처

```bash
pnpm build && pnpm start                    # 터미널 1
pnpm screens --out screenshots              # 터미널 2: 봇 9명이 노는 동안 43장을 단계별로 저장
pnpm clock-sim                              # 시계 동기화 정확도 표
pnpm load --count 150 --flow tiltrace       # 부하 테스트 표
```
