# 게임

모든 게임의 규칙은 `packages/shared/src/games/`에 순수 로직으로 있고, 판정은 서버에서만 합니다. 각 게임의 큰 화면·폰 화면은 `apps/web/src/games/`에 있습니다. 설정 기본값은 방을 만들 때 바꿀 수 있습니다.

참여를 망설이게 만드는 세 가지(쪽팔림, 부담, 귀찮음)를 피하도록 공통 원칙을 정했습니다.

- **혼자 튀지 않는다**: 모두가 동시에 움직이고, 벌칙도 여럿이 함께 받습니다.
- **폰이 대신 민망해 준다**: 동물 소리는 폰이 내고, 벌칙 문구는 화면이 읽어 줍니다.
- **설명이 필요 없다**: 폰 화면에는 지금 할 행동 하나만 있습니다. 규칙은 소개 화면 네 줄로 끝납니다.
- **탈락해도 계속 논다**: 눈치게임은 탈락이 없고, 소수결 탈락자는 예언자가 됩니다.

---

## ① 디지털 눈치게임 · 3분 · 3명 이상

> 설명 없이 바로 웃음이 터지는 오프닝

**규칙**: 화면 전체가 버튼입니다. 누르면 다음 숫자를 외친 것이 됩니다. 같은 숫자를 0.3초 안에 겹쳐 누르면 겹친 사람 모두 벌칙, 끝까지 못 누른 마지막 한 명도 벌칙입니다. 탈락 없이 매 라운드 다시 도전합니다.

**판정**: 도착 순서가 아니라 시계 동기화로 보정한 **누른 순간**으로 판정합니다. 첫 탭 뒤 충돌 창(300ms) + 지연 여유(150ms)를 기다렸다가 확정하므로 느린 폰도 공정합니다. 충돌이 나면 큰 화면에 0~300ms 눈금 위로 누른 순간을 찍어 "79ms 차이" 같은 장면을 보여 줍니다.

**팩 연동**: 벌칙 문구 (예: "다음 모임 장소 정하기")

| 설정      | 기본값          |
| --------- | --------------- |
| 라운드 수 | 5               |
| 충돌 창   | 300ms (150~600) |

**기록**: 가장 아슬아슬한 충돌(ms), 벌칙 최다 인원

## ② 소리 짝꿍 · 5분 · 4명 이상

> 같은 소리를 내는 사람을 귀로 찾아라

**규칙**: 버튼을 누르면 내 폰에서 동물 소리가 납니다. 같은 소리를 내는 사람을 찾아가 그 사람의 QR을 찍습니다(카메라가 안 되면 4자리 숫자 입력). 팀원 누구 한 명과만 이어져도 연결되고, 팀이 다 모이면 밸런스 질문 하나에 팀 의견을 통일하는 미션을 받습니다.

**판정**: 참가자를 최대 4명씩 고르게 팀으로 나누고(10명이면 4·3·3) 팀마다 다른 동물 소리를 줍니다(8종, 넘치면 "두 번 빠르게 우는" 변형). 연결은 유니온-파인드로 묶어서 팀원 전체가 하나로 이어지면 완성입니다. 다른 팀 사람을 찍으면 "헛걸음"으로 기록하고 상대 소리를 알려 줍니다. 시간이 끝나면 못 모인 사람도 자기 팀에 합류하고, 도중에 들어온 사람은 가장 작은 팀에 들어갑니다. 가상 참가자(봇)를 넣었으면 사람끼리, 봇끼리 따로 팀을 만들어 사람이 봇을 찾아 헤매지 않게 합니다. 같은 사람을 여러 번 잘못 찍어도 헛걸음은 한 번만 셉니다.

**왜 말문이 트이나**: 소리를 확인하려면 다가가서 "혹시 염소예요?"라고 물어야 합니다. 처음 보는 사람에게 말을 거는 이유를 게임이 만들어 줍니다.

**팩 연동**: 팀 이름, 미션용 밸런스 질문 (`{name}이 더 좋아할 것 같은 쪽은?` 등)

| 설정         | 기본값 |
| ------------ | ------ |
| 찾기 시간    | 180초  |
| 팀 미션 시간 | 30초   |

**기록**: 팀 완성 순위·시간, 얼굴 보고 연결한 횟수, 헛걸음 수, 만장일치 팀 수. 여기서 만든 팀을 이후 팀 게임이 이어받습니다.

## ③ 비대칭 금고 따기 · 8분 · 2명 이상 (팀)

> 각자 조각만 보고, 말로 합쳐야 열린다

**규칙**: 팀원마다 화면에 보이는 정보가 다릅니다. 화면은 꾹 누르고 있을 때만 보이고, 다른 사람에게 보여주면 안 됩니다. 틀리면 3초 잠기고, 금고는 3개이며 뒤로 갈수록 어려워집니다.

| 역할               | 보이는 것                                |
| ------------------ | ---------------------------------------- |
| 순서 담당          | 기호의 순서 (예: 제주도 → 하나 → 단골집) |
| 해독 담당          | 기호 → 숫자 변환표 (가짜 기호 섞임)      |
| 입력 담당          | 숫자 다이얼과 열기 버튼                  |
| 규칙 담당 (금고 3) | "둘째 자리에 1을 더하라" 같은 변환 규칙  |
| 검산 담당 (4인 팀) | 정답 자릿수의 합                         |

**판정**: 퍼즐은 시드로 생성합니다. 금고 1은 3자리·가짜 기호 2개, 금고 2는 4자리·가짜 4개, 금고 3은 규칙이 추가됩니다. 금고마다 역할을 돌려서 모두 한 번씩 "설명하는 쪽"이 됩니다. 서버는 역할별 정보만 해당 폰에 보내므로 화면을 엿볼 방법이 없습니다. 입력 담당이 나가면 남은 팀원에게 역할이 넘어갑니다.

**팩 연동**: 인물 이름과 키워드가 금고 기호가 됩니다. 모자라면 "빨간 별" 같은 기본 기호로 채웁니다.

| 설정    | 기본값  |
| ------- | ------- |
| 금고 수 | 3 (1~5) |

**기록**: 팀 순위, 가장 빠른 해제, 말로 연 금고 비율

## ④ 인간 카드섹션 · 3분 · 인원 무관

> 폰을 들고만 있으면 방 전체가 하나의 화면이 된다

**규칙**: 좌석 격자에서 지금 내 자리를 누르고, 화면 밝기를 최대로 올려 폰을 머리 위로 듭니다. 한 자리에는 한 사람만 앉을 수 있고, 설정한 격자보다 사람이 많으면 격자가 저절로 넓어져 모두 앉을 자리가 생깁니다. 나간 사람의 자리는 다시 비워집니다.

**연출 (40초)**: 카운트다운 3·2·1 → 색 파도가 왼쪽에서 오른쪽으로 두 번 → 금고 순위대로 팀 색이 하나씩 켜짐 → 열마다 한 글자씩 마지막 문구(길면 오른쪽에서 흘러 들어옴) → 가운데부터 금색으로 번져 하나가 된 뒤 동시에 꺼짐.

**동기화**: 프레임을 보내지 않습니다. 서버는 시작 시각과 파라미터를 한 번 보내고, 모든 폰이 같은 함수 `showFrame(파라미터, 내 자리, 서버 시각)`으로 매 프레임을 계산합니다. 자세한 내용은 [아키텍처 7절](architecture.md#7-카드섹션-프레임을-보내지-않는-동기-연출).

**팩 연동**: 마지막 문구 (예: "3팀 화이팅"), 팀 색

| 설정      | 기본값                    |
| --------- | ------------------------- |
| 좌석 격자 | 6행 × 8열                 |
| 연출 길이 | 40초 (4~120초, 비율 유지) |

## ⑤ 소수결 서바이벌 (추가) · 4분 · 3명 이상

> 다수가 되면 탈락. 설득하고, 동맹하고, 배신하라

**규칙**: 질문이 뜨면 작전 타임에 마음껏 상의합니다. 투표가 끝나면 더 많이 고른 쪽이 탈락합니다. 동점이거나 모두 같은 쪽이면 무효, 투표를 안 하면 탈락입니다. 탈락하면 예언자가 되어 다음 라운드의 소수 쪽을 맞혀 점수를 모읍니다.

**왜 추가했나**: 소수가 되려면 남들이 무엇을 고를지 알아야 하므로, 작전 타임에 자연스럽게 "너 뭐 고를 거야?"가 오갑니다. 탈락자도 예언으로 끝까지 참여합니다.

**팩 연동**: 밸런스 질문, 이름·키워드로 만든 질문

| 설정                  | 기본값      |
| --------------------- | ----------- |
| 라운드                | 5           |
| 작전 타임 / 투표 시간 | 20초 / 10초 |

## ⑥ 군중 조종 레이스 (추가) · 2분 · 2명 이상 (팀)

> 팀원 전원의 기울기 평균으로 배 한 척을 조종하라

**규칙**: 폰을 좌우로 기울이면 팀 배가 움직입니다. 팀원 모두의 기울기 평균으로 움직이므로 말로 맞춰야 합니다. 바위에 부딪히면 1.2초 동안 느려집니다. 센서가 안 되는 폰은 화면의 왼쪽·오른쪽 버튼을 꾹 누릅니다.

**판정**: 폰이 초당 8번 기울기를 보내고, 서버가 팀별 평균(1.5초 넘은 값은 제외)으로 배의 위치와 충돌을 계산합니다. 모든 팀이 같은 코스를 달려 공정합니다. 큰 화면은 레인별 캔버스로 그립니다.

**왜 추가했나**: 한 사람이 잘해서는 이길 수 없고 "왼쪽! 왼쪽!" 소리치며 박자를 맞춰야 합니다. 마지막 카드섹션 전에 몸을 쓰는 순서로 넣기 좋습니다.

| 설정      | 기본값                     |
| --------- | -------------------------- |
| 코스 길이 | 45 (최고 속도로 45초 거리) |

## ⑦ 라이어 게임 (추가) · 6분 · 3명 이상 (테이블)

> 우리 테이블에 제시어를 모르는 사람이 한 명 있다

**규칙**: 테이블(팀)마다 한 명이 라이어입니다. 다른 사람은 제시어를 보고, 라이어는 카테고리만 봅니다. 폰에 나온 순서대로 한 사람씩 제시어를 한마디로 설명하고, 다 말했으면 폰으로 라이어를 지목합니다. 가장 많이 지목된 사람이 라이어면 검거, 동점이거나 엉뚱한 사람이면 라이어가 도망칩니다. 잡힌 라이어는 보기 8개 중 제시어를 맞히면 역전승합니다.

**큰 모임에 맞춘 점**: 여러 테이블이 동시에 하므로 테이블마다 같은 카테고리의 **다른 제시어**를 줍니다 (옆 테이블을 엿들어도 소용없게). 제시어는 화면을 **누르고 있을 때만** 보여서 옆 사람이 훔쳐볼 수 없습니다. 첫 발언자는 라이어가 아닌 사람으로 뽑고, 같은 사람이 연달아 라이어가 되지 않게 돌립니다. 3명보다 작은 팀은 다른 팀에 합칩니다.

**점수**: 검거하면 시민마다 1점, 도망친 라이어 3점, 역전승한 라이어 2점. 큰 화면에 "속이기 장인"이 뜹니다.

**팩 연동**: 키워드가 8개 이상이면 첫 라운드 카테고리가 "우리 모임 키워드"가 됩니다. 없으면 모임 종류에 맞는 카테고리(노는 날 / 회사 생활 / 학교생활)부터 시작합니다.

**왜 가져왔나**: 예능과 보드게임으로 국내에서 가장 널리 알려진 파티게임 중 하나라 규칙 설명이 필요 없습니다. 무엇보다 "돌아가며 한마디씩"이라는 순서가 있어서, 조용한 사람도 자기 차례에 반드시 말하게 됩니다.

| 설정      | 기본값 |
| --------- | ------ |
| 라운드    | 2      |
| 설명 시간 | 90초   |

## ⑧ 파장 맞추기 (추가) · 5분 · 2명 이상 (팀)

> 한 명이 한마디 하면, 팀이 바늘로 마음을 맞춰요

**규칙**: "차가운 ↔ 뜨거운"처럼 양 끝이 있는 눈금 위에 팀마다 비밀 지점이 있습니다. 출제자만 그 지점을 보고, 그 위치를 가리킬 무언가를 한마디로 말합니다 (예: 70쯤이면 "찜질방"). 나머지는 폰에서 바늘을 움직이고, **팀원 바늘의 평균**이 팀의 답입니다. 모두 확정하면 바로 공개합니다. 정중앙(±4) 4점, 가까우면(±10) 3점, 근처(±17) 2점. 출제자는 라운드마다 바뀝니다.

**판정**: 바늘은 0.12초마다 한 번씩만 서버로 보내고, 팀원들의 바늘이 서로의 폰에 실시간으로 보입니다. 아무도 바늘을 놓지 않으면 가운데(50)로 칩니다.

**왜 가져왔나**: 보드게임 Wavelength의 구조입니다. 정답이 없는 감각을 맞추는 게임이라 "그게 왜 뜨거워?" 같은 대화가 저절로 나오고, 평균으로 합치니 혼자 우겨서는 안 되고 팀이 말로 모아야 합니다. 이미 아는 사이(팀 워크숍)에서도 서로의 기준을 알게 되는 재미가 있습니다.

| 설정           | 기본값 |
| -------------- | ------ |
| 라운드         | 3      |
| 한 라운드 시간 | 60초   |

## 세션이 끝난 뒤

큰 화면 아래 띠와 리모컨에 **같은 사람들과 한 판 더 / 리포트 크게 보기 / 게임 바꿔서 새 방 / 처음으로**가 있습니다. 한 판 더를 누르면 같은 팩·게임 순서·설정으로 새 방이 열리고, 진행자 토큰과 PIN이 이어져 큰 화면과 리모컨이 저절로 새 방으로 옮겨 갑니다. 참가자 폰에는 "다음 판 들어가기"가 떠서 누르면 같은 닉네임으로 바로 들어갑니다. 설문을 하기 싫은 사람은 "설문 건너뛰고 나가기"로 나갈 수 있습니다.

## 새 게임 추가하기

1. `packages/shared/src/games/<id>.ts`에 `GameModule`을 구현합니다 (`init / input / tick / hostView / playerView / summary`).
2. `games/types.ts`의 `GameId`, `games/index.ts`의 `GAMES`에 등록합니다.
3. `apps/web/src/games/<id>.tsx`에 큰 화면·폰 컴포넌트를 만들고 `games/index.ts`의 `HOST_VIEWS`, `PLAYER_VIEWS`, `STAGE_TONE`에 등록합니다.
4. `tools/src/bot.ts`에 봇의 행동을 추가하면 통합 테스트와 부하 테스트가 새 게임도 플레이합니다.

서버 코드는 바꿀 필요가 없습니다.
